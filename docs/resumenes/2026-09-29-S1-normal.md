## 2. El proyecto

- Plantilla **Empty Views Activity** (vistas XML; la *Empty Activity* es la de Compose, que el spec excluye).
- `namespace` y `applicationId` = **`yunkang.ako`** (P104; sustituye a `es.daniel.ako` del spec). El `applicationId` identifica la app de forma única en el dispositivo y en las tiendas: si cambia, Android la trata como otra app. El `namespace` es el paquete de la clase `R` y del código.
- **`minSdk 26`**: `SecretKeyFactory.getInstance("PBKDF2WithHmacSHA256")`, necesario para guardar el PIN como sal + hash (regla del spec: nunca en claro), está disponible desde la API 26; así no hace falta ninguna librería de criptografía externa (el spec las prohíbe). Cobertura según el asistente: ~98,4 % de los dispositivos.
- **`compileSdk` y `targetSdk` 37**: se compila contra la API más reciente (Glide 5.0.9 la exige) y se declara que la app está probada para ella. `minSdk` es el suelo; `targetSdk`, el comportamiento para el que está pensada.
- `app_name` = **AKO** (P105).

## 3. Configuración de Gradle (del `stack-verificado`, P106: copiada por Claude)

- **`gradle/libs.versions.toml`** — el **catálogo de versiones**: bloques `[versions]`, `[libraries]` (alias → coordenadas Maven + `version.ref`) y `[plugins]`. Un único sitio para las versiones de las **dependencias**; no tiene que ver con la versión de la app (`versionCode`/`versionName`, en `app/build.gradle.kts`).
- **`app/build.gradle.kts`** — plugins `com.android.application` y `com.google.devtools.ksp`; `compileSdk`/`minSdk`/`targetSdk`; `testInstrumentationRunner`; `buildFeatures { viewBinding = true }`; Java 17; dependencias:
  - base de AndroidX: `core-ktx`, `appcompat`, `material`, `constraintlayout`, `recyclerview`, `activity-ktx`, `fragment-ktx`;
  - MVVM: `lifecycle-viewmodel-ktx`, `lifecycle-livedata-ktx`, `kotlinx-coroutines-android`;
  - **Room** 2.8.5 (`room-runtime`, `room-ktx`, `ksp(room-compiler)`) y **Glide** 5.0.9 (`glide`, `ksp(glide ksp)`);
  - pruebas: `junit` (`test/`), `room-testing`, `androidx.test.ext:junit` y `runner` (`androidTest/`).
- **`build.gradle.kts`** raíz: declara los plugins con `apply false`.
- **`settings.gradle.kts`**: repositorios (Google, Maven Central), `rootProject.name = "AKO"`, módulo `:app`.
- **`gradle.properties`**: `android.useAndroidX`, `kotlin.code.style=official`, `android.nonTransitiveRClass`.
- **KSP** (Kotlin Symbol Processing) genera código a partir de anotaciones (`@Entity`, `@Dao`, `@GlideModule`). Por eso existe `imagenes/AkoGlideModule.kt` (una clase `AppGlideModule` vacía): sin ella Glide con KSP no compila. Prueba de que funciona: `GeneratedAppGlideModuleImpl` en `java (generated)`.
- **Kotlin 2.2.10** va integrado en AGP 9: no se declara el plugin `org.jetbrains.kotlin.android`.
- Verificación: `assembleDebug` y `testDebugUnitTest` en verde; *Sync* y *Run* correctos en Android Studio.
